# Семантические элементы

## Что это

Семантический элемент — это типизированный, структурно осмысленный building-блок, произведённый
[извлечением](extraction.ru.md) — наименьшая единица, которую платформа распознаёт как имеющую конкретную
роль в структуре источника.

## Почему это нужно

Необработанный текст не знает понятий «это заголовок» или «эти цифры образуют таблицу». Семантические
элементы существуют для того, чтобы понимание платформой *формы* документа сохранялось после границы
извлечения, а не превращалось в неразличимую стену текста прежде, чем с ней можно будет сделать что-либо
полезное.

## Как это работает

Семантические элементы могут представлять:

```text
Документ
Страница
Раздел
Абзац
Таблица
Ячейка
Изображение
Подпись
Аудиосегмент
Говорящий
Сцена видео
Сегмент транскрипта
```

Каждый элемент несёт свой тип, своё положение в структуре источника и (где применимо) диапазон страниц или
времени. Элементы не зависят от медиатипа по *типу*, даже если процесс извлечения, который их произвёл,
полностью специфичен для конкретного медиа.

## Пример

Запись звонка службы поддержки производит по одному элементу `AudioSegment` на каждую реплику говорящего,
каждый с идентичностью `speaker` и диапазоном `[start_time, end_time]`. PDF-инвойс производит элемент
`Table` для таблицы позиций, с дочерними элементами `Cell`, а также элементы `Paragraph` и `Heading` для
окружающего текста.

## Входные данные

Структурированный payload, выданный [извлечением](extraction.ru.md) для конкретного источника.

## Выходные данные

Дерево типизированных элементов, потребляемое [семантическим чанкированием](semantic-chunking.ru.md) для
получения [семантических чанков](chunks.ru.md).

## Преобразования

На этом уровне отсутствуют — семантические элементы являются результатом извлечения, а не тем, что
подвергается дальнейшим преобразованиям до этапа чанкирования.

## Зависимости

Зависят от того, что [извлечение](extraction.ru.md) успешно разобрало медиатип источника.

## Изменение и пересчёт

Изменение логики извлечения для медиатипа меняет семантические элементы, произведённые для затронутых
источников, что каскадно влияет на чанкирование, аннотирование и каждую нижестоящую проекцию.

## Безопасность

Семантические элементы не несут классификации — классификация является свойством
[семантического чанка](chunk-security.ru.md), построенного из них, а не самих исходных элементов.

## Происхождение

Каждый нижестоящий чанк сохраняет указатель на конкретные семантические элементы, из которых он был
построен.
